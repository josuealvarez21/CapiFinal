# Cápi

Plataforma moderna, intuitiva y eficiente diseñada para tomar el control de tus finanzas personales. Este proyecto te permite gestionar tus gastos, ingresos y analizar tu economía de forma ágil y segura.

## Tecnologías

- **Frontend:** React / Next.js / Tailwind CSS
- **Backend:** Python / FastAPI
- **Base de datos:** MySQL

## Avances y Características Actuales

- **Arquitectura Completa:** Integración funcional entre el backend en FastAPI y el frontend interactivo en Next.js.
- **Gestión de Base de Datos:** Scripts automatizados para la inicialización, configuración y solución de problemas de la base de datos MySQL (`init_db.py`, `fix_db.py`, `add_column.py`).
- **Pruebas Automatizadas:** Implementación de tests para asegurar la calidad de componentes clave como el backend, el dashboard y el registro de usuarios (`test_backend.py`, `test_dashboard.py`, `test_signup.py`).
- **Automatización de Ejecución:** Script de ejecución unificado (`run_all.bat`) que valida la conexión a la base de datos y levanta de manera simultánea los servidores de backend y frontend.
- **Autenticación y Seguridad:** Integración de JWT y encriptación de contraseñas (Bcrypt) configurada en el ecosistema.
